# hiWeather App

<img src="https://i.ibb.co/4sPMDMd/hhw-weather-app.png" alt="Vue ShowTheWeather Application" width="600" height="400"/>

**hiWeather** is a Vue.js application that shows real-time weather via the OpenWeather API, showcasing front-end development, API integration, dynamic data handling and responsive, user-focused web solutions.

## Key Features

- Retrieve real-time weather data for any city using the OpenWeather API
- Display temperature, humidity, wind speed, and weather conditions
- Dynamic UI updates using Vue.js reactive components
- Error handling for invalid city input
- Responsive design for desktop and mobile devices

## Technical Focus

This project highlights:

- **Front-end:** Vue.js for building reactive and interactive UI components
- **API Integration:** OpenWeather API for fetching real-time weather data
- **Data Handling:** Dynamic updates and error handling with reactive data binding
- **Design:** Modular component structure and responsive layout
- **Learning Outcome:** Hands-on experience with API integration and modern JavaScript frameworks

## Getting Started

### Prerequisites

- Node.js and npm installed
- Basic understanding of Vue.js

### Installation

1. Clone the repository:
```bash
git clone https://github.com/techgirldiaries/hiWeather.git
```
2. Navigate to the project directory:
```bash
cd hiWeather
```
3. Install dependencies:
```bash
npm install
```
4. Run the development server:
```bash
npm run serve
```
